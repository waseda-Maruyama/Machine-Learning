\section{序論}
\subsection{研究背景}
金融市場における価格形成は、多様な因子が相互に影響を及ぼし合う極めて複雑な現象であり、その予測手法の確立は学術的・実務的に喫緊の課題である。近年、計算機能力の向上とデータ蓄積に伴い、
深層学習をはじめとする機械学習を用いた市場予測が盛んに行われてきた。これらの手法は、従来の統計モデルを上回る高い予測精度を実現する一方で、実務上の必須要件である「説明可能性」と「頑健性」に重大な課題を残している。
従来の機械学習によるアプローチは、高次元なデータから相関関係を抽出することには長けているが、その予測プロセスはブラックボックス化しやすい。このため、モデルが市場のノイズを過学習し、
未知の暴落局面（アウト・オブ・サンプル）に対して極めて脆弱になるという欠陥を有している。高次元の非線形相関を学習したモデルは、その予測根拠が物理的な因果律と整合しているか検証することが困難であり、
特に学習データに含まれない未知の局面（Out-of-Distribution）において、物理法則に反する挙動を示すリスクがある。
一方で、複雑系科学の一分野である経済物理学では、金融市場を多数の要素が相互作用する動的システムと捉え、その構造変化を物理現象として記述する研究が進められてきた。
特にランダム行列理論（Random Matrix Theory; RMT）は、多数の銘柄間の相関行列から統計的ノイズを分離し、市場の本質的な相互作用を抽出する強力な手法として知られている。
先行研究\cite{cite:1}によれば、市場に大規模なショックが加わる際、全セクターの相関が急速に強まる「同期現象」が観測される。これは物理学におけるイジングモデルの「相転移」とのアナロジーとして解釈可能であり、
システマティック・リスクの先行指標として極めて有用であると考えられる。
このように、高度な非線形パターンの学習能力を持つ機械学習と、物理的妥当性に基づくノイズ除去および解釈性を備えた経済物理学的指標を統合することは、データ駆動型アプローチの欠陥を物理法則で補完し、
暴落の予兆からその後の収束に至る市場の動態を包括的に記述する、新たな金融予測フレームワークの構築へと繋がると期待される。
さらに、機械学習モデルの探索空間に物理的な制約（Inductive Bias）を与えることで、未知の局面に対する頑健性（Robustness）を向上させる点も重要である。
また、理論的な必要性だけでなく、近年の投資プラットフォームの普及に伴う新規参入者の急増のような現実の市場構造の変化も、この物理学的アプローチの必要性を支持している。
日本証券業協会\cite{cite:2}の調査によれば、
2024年度の個人株主数は約1600万人に達し、増加傾向であることを示している。また、図\ref{fig:1.1} (a)より、
投資家が複数の銘柄を跨いで保有している数である平均の株式保有数も上昇している。
これは銘柄（要素）間に「投資家」という媒体を通じた強い結合が網の目状に張り巡らされている状態に相当する。

さらに、図\ref{fig:1.1} (b)は、特に若年層を含む投資未経験者の市場流入を端的に示している。
十分な経験や知識、あるいは厳密な投資規律を持たないこれら多数の投資家は、ファンダメンタルズに基づかない感情的な売買や、
SNSを通じた「模倣行動」を行いやすく、系全体の相互作用を増大させる要因となる。
したがって、各要素が独立かつ合理的に振る舞う理想的な市場モデルはもはや現実的ではないことが懸念される。
そのため、情報の非対称性と強い相互作用が支配する市場を統計力学的な「複雑系」と見なし、マクロな秩序（相関構造）の変化を捉える手法が必要となる。
また、従来、時系列解析においては定常性を確保するために対数収益率（速度）のみが重視され、価格そのもの（位置）やその二乗項は除外される傾向にあった。
しかし、物理学的な観点、特に量子調和振動子（Quantum Harmonic Oscillator）モデルの視座に立てば、価格の二乗は系に蓄積された「ポテンシャルエネルギー（Potential Energy）」として解釈可能である。 
市場価格が平衡点から乖離するほど、システムには「歪み」としてのエネルギーが蓄積され、これが臨界点を超えた際に相転移（暴落）として解放される。


\subsection{研究目的}
本研究の目的は、金融市場における銘柄間の相関構造の動態を、統計力学における「相転移」の枠組みで捉え直し、ランダム行列理論（RMT）に基づく物理指標を機械学習モデルに導入することで、
暴落の発生からその後の市場復帰に至る一連の遷移過程を精度高く捉える新たな予測フレームワークを構築することである。具体的には、日本市場の代表的な株価指数であるTOPIX100構成銘柄を対象とし、
以下の三点を検証の柱とする。第一に、RMTを用いて相関行列から統計的ノイズを除去し、市場全体の同期性を表す最大固有値 $\lambda_{\max}$ を抽出する。
一般に暴落時は市場全体が強い相関を持つ「秩序状態」へと遷移するが、本研究ではこの「秩序化（暴落）」および、そこから各銘柄が固有の動きを取り戻す「無秩序状態への回帰（回復）」の両面を定量的に捕捉可能か検証する。
第二に、予測モデルとしてLightGBMを採用し、物理指標の導入が、従来のテクニカル指標のみでは困難であった暴落の先行検知、
および「過度な同期状態からの脱却（底打ち）」の判別精度に与える影響を明らかにする。
第三に、SHAPを用いた特徴量寄与度の分析により、モデルが市場の同期・非同期の切り替わりをどのように学習し、
本研究の最大の独自性は、市場を物理的な多体システムとして捉え直す点にある。特に、「市場ポテンシャルエネルギー」を明示的にモデルに組み込むことで、
速度（ボラティリティ）のみに依存していた従来の予測モデルが抱える「位置情報の欠落」という課題を解決し、暴落の予兆を物理的必然性を持って検知することを目指す。

\section{伝統的経済学と経済物理学}
\subsection{伝統的経済学とその限界}
本研究で用いる経済物理学的アプローチの妥当性を論じるにあたり、まず伝統的な金融経済学の基礎となる諸仮説とその工学的観点からの限界について述べる。
\subsubsection{効率的市場仮説とランダムウォーク}
伝統的金融理論の根幹をなす「効率的市場仮説（Efficient Market Hypothesis; EMH）」は、市場の全ての情報が即座に価格に反映されると仮定する\cite{cite:5}\cite{cite:6}。このとき、価格の変化（収益率）は互いに独立な確率変数となり、
その推移は「ランダムウォーク」として記述される。工学的なシステムに照らせば、これは系に「記憶」や「慣性」が存在せず、過去の入力が未来の状態に一切影響を及ぼさない、極めて特殊な平衡状態を仮定していることに相当する。

\subsubsection{幾何ブラウン運動とブラック・ショールズモデルの数理}
伝統的な金融モデルの多くは、価格変動の確率分布として「正規分布（ガウス分布）」を前提としている\cite{cite:7}。正規分布は中心極限定理に基づき、多くの独立した事象の総和が収束する自然な分布とされるが、
金融市場においてはこれが致命的な計算ミスを招く要因となる。
具体的な例として、オプション価格算定モデルであるブラック・ショールズ方程式（Black-Scholes Equation）が挙げられる。現代ファイナンス理論の金字塔である
ブラック・ショールズモデル（Black-Scholes Model）は、株価の確率的挙動を記述するために、以下の確率微分方程式（Stochastic Differential Equation: SDE）を出発点とする。
\begin{equation}dS_t = \mu S_t dt + \sigma S_t dW_t\end{equation}
ここで、$S_t$は時刻$t$における株価、$\mu$はドリフト（期待収益率）、$\sigma$はボラティリティ、そして$W_t$はウィーナー過程（標準ブラウン運動）である。
このモデルは、株価の対数収益率が正規分布に従うこと、すなわち「対数正規分布（Lognormal Distribution）」を前提としている 。
伊藤の補題（Itô's Lemma）を用いることで、対数株価 $\ln S_t$ のダイナミクスは以下のように導出される。
\begin{equation}d(\ln S_t) = \left( \mu - \frac{\sigma^2}{2} \right) dt + \sigma dW_t\end{equation}
この式は、ある期間 $t$ における対数収益率が、平均 $(\mu - \sigma^2/2)t$、分散 $\sigma^2 t$ の正規分布に従うことを意味する。
正規分布（ガウス分布）は、中心極限定理に基づき、独立かつ同一の分布に従う（i.i.d.）多数の小さな衝撃の総和として自然界に広く観察される分布である。
しかし、この「独立性（Independence）」と「定常性（Stationarity）」の仮定こそが、金融市場の暴落を説明する上での致命的な欠陥となる。正規分布の確率密度関数は $e^{-x^2}$ で減衰するため、
平均から標準偏差の数倍（例えば $5\sigma$ や $10\sigma$）離れた事象が発生する確率は、天文学的に低くなる。これを「薄い裾（Thin Tail）」と呼ぶ。
現実には、ブラックマンデー（1987年）における20$\%$を超える下落のような事象は、ガウス分布の世界では宇宙の年齢を待っても起こり得ない確率であるが、現実には数十年単位で発生している 。

\subsubsection{ファットテールとべき乗則}
正規分布では説明できない「ファットテール（Fat tail）」と呼ばれる特性を持つ。正規分布においては、平均から標準偏差の数倍（例えば $6\sigma$ 以上）離れたイベントが発生する確率は天文学的に低く、
実質的に「起こり得ないこと」として切り捨てられる。ところが、現実の金融市場では、ブラックマンデーやリーマンショック、あるいは本研究が対象とするような急激な暴落が、
正規分布の予測を数千倍、数万倍も上回る頻度で発生する。「ファットテール」現象は、Benoit Mandelbrot（1963）の綿花価格の分析によって初めて厳密に指摘された。
彼は、価格変動の分布がガウス分布ではなく、「安定パレート分布（Stable Paretian Distribution）」、特にレヴィ安定分布（Lévy Stable Distribution）に従うことを提唱した。
レヴィ分布の特徴は、その裾（テール）が以下のべき乗則（Power Law）に従って減衰することにある。
\begin{equation}
P(|r| > x) \sim x^{-\alpha}
\end{equation}
ここで、αはパレート指数と呼ばれる。ガウス分布の場合、形式的に$\alpha \to \infty$とみなせるが、実際の金融市場データ（特に先進国の株式市場）では、
$\alpha \approx 3$（逆三乗則：Inverse Cubic Law）となることが多くの実証研究で示されている\cite{cite:8}\cite{cite:9}。$\alpha < 2$の場合、分布の分散は無限大に発散し、
標準偏差$\sigma$という概念自体が意味をなさなくなる。これは、平均分散アプローチ（Mean-Variance Approach）に基づく現代ポートフォリオ理論（Modern Portfolio Theory: MPT）の根底を揺るがすものである。
これは、市場を構成する各銘柄や投資家の行動が「独立」ではなく、暴落時には互いに強く影響を及ぼし合う「相互作用」を持つためである。独立性を前提とする伝統的な統計モデルでは、
こうした相互作用によって生じる集団的な「相転移」としての暴落を捉えることは理論上不可能である。この分布の「裾」に隠れたリスクを定量化するためには、
正規分布の枠組みを超え、次節で述べる多体系の相関を扱うランダム行列理論のような、物理学的なアプローチが必要不可欠となる。

\subsubsection{限定合理性と複雑系としての市場}

さらに、伝統的経済学は「ホモ・エコノミクス（完全合理的な人間）」を仮定するが、現実には投資家の「認知限界」や、
他者の行動を模倣する「群集心理」が存在する\cite{cite:10}。つまり、個々の要素の単純な総和では説明できない「集団的挙動（Collective Behavior）」
が市場には内在している。具体的には、「ボラティリティ・クラスタリング」とよばれる現象である。
これは、「大きな価格変動の後には大きな変動が続き、小さな変動の後には小さな変動が続く」という現象であり、
収益率の絶対値 $|r_t|$ や二乗 $r_t^2$ に長期記憶（Long Memory）が存在することを意味する 。
\begin{equation}Corr(|r_t|, |r_{t+\tau}|) > 0 \quad (\text{for large } \tau)\end{equation}
この現象は、市場参加者（エージェント）が互いに独立して行動しているのではなく、
過去の価格変動や他者の行動に影響を受けていることを示唆している。すなわち、系の中に「相互作用（Interaction）」が存在する。
この相互作用こそが、統計力学における強磁性体のモデルであるイジングモデルを金融市場に応用する最大の根拠となる。
ブラック・ショールズモデルのような伝統的モデルは、外部からのニュース（外場）のみが価格を動かすと仮定しがちだが、
実際の暴落の多くは、明確なニュースがない中で、市場内部の相互作用の連鎖（雪崩現象）によって引き起こされる。
Sornetteらはこれを「内在的クラッシュ（Endogenous Crash）」と呼び、外在的ショック（Exogenous Shock）と区別した

\subsection{イジングモデルによる市場の記述と相転移}
金融市場における暴落現象を、多数の要素が相互作用を通じてマクロな秩序を形成する「相転移」として捉えるため、
統計力学の代表的なモデルであるイジングモデル（Ising Model）とのアナロジーを導入する。


\subsubsection{イジングモデルの定義とハミルトニアン}
本研究では、先行研究\cite{cite:11}や\cite{cite:12}と同様に金融市場を巨大な熱浴（外部環境）と接触し、エネルギーのやり取りを行う閉じた系と見なす。統計力学において、このような系は正準集団（Canonical Ensemble）によって記述される。
系を構成する $N$ 個の要素（スピン）の状態を $s_i \in \{+1, -1\}$ とし、系の微視的状態（Microstate）をベクトル $\mathbf{s} = \{s_1, s_2, \dots, s_N\}$ で表す。
このとき、系の全エネルギーを与えるハミルトニアン $\mathcal{H}(\mathbf{s})$ は次式で定義される。
\begin{equation}\mathcal{H}(\mathbf{s}) = - \sum_{\langle i,j \rangle} J_{ij} s_i s_j - h \sum_{i=1}^{N} s_i\end{equation}
ここで、$J_{ij}$ は相互作用係数、$h$ は外部磁場である。正準集団において、温度 $T$ の熱浴と平衡状態にある系が、
特定の微視的状態 $\mathbf{s}$ をとる確率 $P(\mathbf{s})$ は、ギブス・ボルツマン因子を用いて以下のように導出される。
\begin{equation}P(\mathbf{s}) = \frac{1}{Z} \exp\left( -\beta \mathcal{H}(\mathbf{s}) \right)\end{equation}
ただし、$\beta$ は逆温度であり、ボルツマン定数 $k_B$ を用いて $\beta \equiv \frac{1}{k_B T}$ と定義される。
ここで導入された正規化定数 $Z$ は分配関数（Partition Function）と呼ばれ、取り得る全ての微視的状態に関する和として定義される。
\begin{align*}
Z(T, h, \{J_{ij}\}) &= \sum_{\{\mathbf{s}\}} \exp\left( -\beta \mathcal{H}(\mathbf{s}) \right) \\
&= \sum_{s_1=\pm 1} \dots \sum_{s_N=\pm 1} \exp\Big[ \beta \Big( \sum_{\langle i,j \rangle} J_{ij} s_i s_j \\
& \quad + h \sum_{i=1}^{N} s_i \Big) \Big]
\end{align*}
この分配関数 $Z$ は、系に含まれる統計的な情報の全てを包含する基本量である。
統計力学の基本原理に基づき、系のヘルムホルツの自由エネルギー $F$ は、分配関数を用いて次のように一意に決定される。
\begin{equation}F(T, h) = -k_B T \ln Z(T, h)\end{equation}
系が平衡状態にあるとき、自然界は自由エネルギー $F$ を最小化するように振る舞う。したがって、本研究において市場の「安定状態」や「相転移」を議論することは、
数学的にはこの分配関数 $Z$ の解析的性質、特にパラメータ空間における特異点を調べることに帰着される。


\subsubsection{相転移と臨界現象}
前節で定義した分配関数 $Z$ を厳密に計算することは、一般に困難である。そこで本研究では、各スピンが隣接スピンから受ける影響を平均化された「有効磁場」として扱う
平均場近似（Mean Field Approximation）を用いて、相転移のメカニズムを導出する。
\begin{description}
\item[(1) 有効ハミルトニアンの導出スピン] $s_j$ を、その熱平均 $m = \langle s_j \rangle$ と、
そこからのゆらぎ $\delta s_j$ の和として表現する。
\begin{equation}s_j = m + \delta s_j\end{equation}
ゆらぎの2次項 $O(\delta s_i \delta s_j)$ を無視すると、相互作用項 $s_i s_j$ は次のように線形化できる。
\begin{equation}
s_i s_j \approx s_i m + m s_j - m^2
\end{equation}
これを元のハミルトニアン $\mathcal{H}$ に代入し、配位数（隣接するスピンの数）を $z$ とすると、多体問題は独立した1体問題の和に分離できる。
特定の注目スピン $s_i$ に関する有効ハミルトニアン $\mathcal{H}_{eff}$ は、定数項を除いて次のように記述される。
\begin{equation}
\mathcal{H}_{eff} = - (zJm + h) s_i
\end{equation}
ここで、$h_{eff} = zJm + h$ は、
外部磁場 $h$ に加え、周囲のスピンから受ける平均的な相互作用（分子場）を表す有効磁場である。
\item[(2) 自己無撞着方程式] この有効ハミルトニアンを用いると、
1スピンあたりの分配関数 $Z_1$ は次のように計算できる。
\begin{equation}Z_1 = \sum_{s_i = \pm 1} \exp\left( \beta h_{eff} s_i \right) = 2 \cosh\left( \beta (zJm + h) \right)\end{equation}
スピンの期待値（磁化）$m = \langle s_i \rangle$ は、統計力学の定義通り $Z_1$ から導出される。
\begin{equation}m = \frac{1}{Z_1} \sum_{s_i = \pm 1} s_i \exp\left( \beta h_{eff} s_i \right) = \tanh\left( \beta (zJm + h) \right)\end{equation}
この式は、磁化 $m$ が右辺の関数の中にも $m$ を含む自己無撞着方程式（Self-consistent equation）となっており、この解を求めることで系の状態が決定される。
\item[(3) 自発的対称性の破れと相転移] 外部磁場がない場合（$h=0$）、方程式は $m = \tanh(\beta zJ m)$ となる。
この方程式が自明な解 $m=0$（無秩序相）以外の非ゼロ解（秩序相）を持つ条件を考える。$\tanh(x)$ の原点付近での傾きが 1 を超えるとき、$m \neq 0$ の解が現れる。
\begin{equation}\left. \frac{d}{dm} \tanh\left( \frac{zJm}{k_B T} \right) \right|_{m=0} = \frac{zJ}{k_B T} > 1\end{equation}この条件を満たす温度領域、すなわち $T < T_c = \frac{zJ}{k_B}$ において、
系は自発的に対称性を破り、非ゼロの磁化 $m$ を持つ強磁性相（秩序状態）へと転移する。この導出過程は、個々の要素（投資家）が周囲の平均的な動向（有効磁場 $zJm$）を「空気」として読み取り、
それに行動を合わせることで、外部からの強制力がなくとも自発的に巨大なトレンド（暴落）が形成されるメカニズムを数学的に保証するものである
\end{description}



\subsubsection{金融市場とのアナロジー}
前節までの物理モデルを基に、本研究における金融市場の捉え方と、RMTを導入する核心的な仮説について述べる。
\begin{description}
\item[(1) 物理量と市場変数の対応] ハミルトニアン $\mathcal{H}$ の各項を、本研究が対象とする市場の具体的な事象に以下のように対応付ける。
\begin{itemize}
    \item スピン $s_i$：各銘柄の価格変動（上昇 $+1$ / 下落 $-1$）。
    \item 外部磁場 $h$：市場全体を揺るがす外部ショック。本研究の実験期間においては「COVID-19パンデミック」や「トランプ大統領の関税発言」などが、全銘柄に売り圧力（$h < 0$）をかける外場に相当する。
    \item 相互作用 $J_{ij}$：銘柄間の連動性。投資家の群集心理やアルゴリズム取引によって形成される「同期圧力」である。
\end{itemize}
\item[(2) 従来のアプローチとの相違点] 従来の経済物理学では、ブラックマンデーのように明確なニュースがないにも関わらず発生した暴落を、内部のゆらぎのみによる「自発的な相転移」として扱う傾向があった。
しかし、現実の運用局面、特に本研究が対象とする2020年代の市場においては、感染症や地政学リスクといった「強力な外部ショック $h$」が常態化している。
\item[(3) アナロジーの再定義] 静的な「予言」から動的な「早期検知」へ 従来、相転移のアナロジーは「臨界点におけるゆらぎ」を捉えることで、暴落を事前に予知しようとする試みが多くなされてきた。
しかし、本研究ではこの視点を、外部ショック h が加わった直後の「過渡応答（ Transient Response ）」の監視へと拡張する。
物理学において、急激な外場の変化に対する系の応答には必ず緩和時間が必要であり、相転移は一瞬にして完了するわけではない。局所的に始まったスピンの配向（売り）が、
相互作用 $J_{ij}$ を介して系全体へ伝播し、マクロな秩序（大暴落 ）が形成されるまでには、「核形成（ Nucleation ）」と「ドミノ倒し的な波及」の時間的ラグが存在する。
\item[(4)RMTによる「相転移の進行」のリアルタイム診断] この「ラグ」の存在こそが、工学的な介入（暴落回避）を可能にする領域である。
外部ショック $h$ の発生自体（例：突発的なニュース）を予測することは困難であっても、その結果として市場内部で「同期（秩序化）が開始された瞬間」を捉えることは可能である。
本研究で導入するRMTの最大固有値 $\lambda_{\max}$ は、この相転移の進行度をリアルタイムで映し出すモニターとして機能する。
\begin{itemize}
    \item 初期段階（ Shock ）: ニュースにより一部の銘柄が反応。まだ $\lambda_{\max}$ は閾値内。
    \item 進行段階（Nucleation）: 相互作用により連鎖的な売りが発生。$\lambda_{\max}$ が急上昇し、ノイズ領域を逸脱する。（ここが検知ポイント）
    \item 崩壊段階（Avalanche）: 全市場が同期し、不可逆的な暴落に至る。
    \end{itemize}
すなわち、本研究の目的は「火種（ショック）」を防ぐことではなく、RMTを用いて「火が燃え広がる予兆（同期の開始）」をいち早く検知し、
火災（致命的な損失）に至る前に避難するための「早期警戒システム（Early Warning Signal）」を構築することにある。
これは、非平衡統計力学における相転移のダイナミクスを、リスク管理に応用する極めて合理的なアプローチである。

\end{description}



\subsection{ランダム行列理論}
前節で述べたように、金融市場における暴落は、多数の銘柄が相互作用によって同期する「相転移現象」として理解できる。
しかし、実際の価格データには個別のニュースや投機的な売買による膨大なノイズが含まれており、生のデータから市場の「秩序変数」を直接観測することは困難である。 
そこで本研究では、原子核物理学において複雑なハミルトニアンの統計的性質を記述するために発展し、複雑系科学に応用されているランダム行列理論（Random Matrix Theory; RMT）を導入する\cite{cite:13}\cite{cite:14}。
\subsubsection{相関行列の構築と統計的性質}
市場内部の相関構造を抽出するため、まず観測データから経験的な相関行列（Empirical Correlation Matrix）を構築する手順を厳密に定義する。 
分析対象となる $N$ 個の銘柄について、時刻 $t$ における価格を $P_i(t)$ とする。金融時系列解析において価格そのものは非定常であるため、通常は対数収益率 $R_i(t)$ を用いる。
\begin{equation}R_i(t)=\ln P_i(t) - \ln P_i(t-1)\end{equation}
ここで対数を取る理由は、価格変動の比率に対する対称性を保ち、かつ時間的な加法性を確保するためである。次に、銘柄ごとにボラティリティ（変動の激しさ）が異なる影響を排除するため、
特定の時間窓 $T$ において平均 $\mu_i$ 、標準偏差 $\sigma_i$ を用いて標準化を行う。
\begin{equation}x_i(t)=\frac{R_i(t) - \mu_i}{\sigma_i}\end{equation}
この正規化された変数 $x_i(t)$ は、平均 0、分散 1 の分布に従う。これを用いて、$N \times N$ の相関行列 $C$ の各成分 $C_{ij}$ を次のように算出する。
\begin{equation}C_{ij}=\langle x_i(t)x_j(t)\rangle=\frac{1}{T}\sum_{t=1}^{T} x_i(t)x_j(t)\end{equation}
あるいは、行列形式で $X$ を $N \times T$ のデータ行列（各行が銘柄、各列が時刻）とすれば、相関行列は
\begin{equation}C=\frac{1}{T} XX^T\end{equation}
$C$ は定義より実対称行列であるため、線形代数学の定理により、$N$ 個の実固有値 $\lambda_1 \le \lambda_2 \le \dots \le \lambda_N$ と、
互いに直交する固有ベクトル $v_k$ を持つことが保証される。この固有値分布の形状を解析することが、RMTの主たる目的である。

\subsubsection{マルチェンコ・パスツール分布}
RMTの核心は、「市場に有意な相関が全く存在しない（純粋なノイズである）」という帰無仮説を設定し、それと比較することで「意味のある情報（シグナル）」を分離することにある。

もし各銘柄の価格変動が完全に独立でランダムなガウス過程に従うと仮定した場合、その相関行列はウィシャート行列（Wishart Matrix）と呼ばれるランダム行列のクラスに属する。
数学者マルチェンコとパスツールは、行列サイズ $N$ とデータ長 $T$ が共に無限大 ($N,T \to \infty$) であり、その比 $Q=T/N \ge 1$ が一定に保たれる極限において、固有値密度関数 $\rho(\lambda)$ が以下の解析解に収束することを証明した。

\begin{equation}
\rho_{MP}(\lambda) = \frac{\sqrt{(\lambda_+ - \lambda)(\lambda - \lambda_-)}}{2\pi\sigma^2\lambda Q} \quad (\text{for } \lambda_- \le \lambda \le \lambda_+)
\end{equation}
ここで、理論的な固有値の存在範囲を示す境界値 $\lambda_{\pm}$ は次式で与えられる。

\begin{equation}
    \lambda_{\pm} = \sigma^2 \left(1 \pm \sqrt{\frac{1}{Q}}\right)^2
\end{equation}
この $\rho_{MP}(\lambda)$ はマルチェンコ・パスツール（Marchenko-Pastur）分布と呼ばれ、相関行列における「熱雑音」のスペクトル特性を記述する。
実際の市場データから得られた固有値分布をこの理論曲線と比較したとき、範囲 $[\lambda_-, \lambda_+]$ に収まる固有値は、単なる統計的なゆらぎ（ノイズ）であると判定され、分析から除外あるいは平滑化の対象となる。

\subsubsection{最大固有値と市場の同期性}
一方、理論的上限 $\lambda_+$ を明確に超えて観測される固有値（逸脱固有値）は、ランダムネスでは説明できない「真の相関」を表している。
中でも、本研究において最も重要視するのが、スペクトルの中で最大の値を持つ最大固有値 $\lambda_{\max}$ である。

\paragraph{マーケット・モードとしての物理的意味}
最大固有値 $\lambda_{\max}$ は、多変量解析における第1主成分の分散に対応し、全銘柄の価格変動に共通して含まれる成分、すなわち「\textbf{マーケット・モード}（Market Mode）」の強度を表す。
物理学的なアナロジーにおいて、この $\lambda_{\max}$ はイジングモデルにおける秩序変数（{磁化 $m$ の二乗}）や、外部要因に対する感受率 $\chi$ と等価な役割を果たす。

\textbf{通常時（無秩序相）}: 市場が平穏な場合、各銘柄は個別の材料（企業の業績等）で独立に動く傾向が強い。このとき、相関行列の非対角成分はゼロに近く、
$\lambda_{\max}$ は理論的境界 $\lambda_+$ 付近、あるいは比較的小さな値に留まる。これは、系全体の自由度が高く、特定のモードが支配的ではないことを意味する。

\textbf{危機の予兆・発生時（秩序化）}: 一方、外部ショック $h$ が加わり、投資家間の相互作用 $J$ によって売りが連鎖すると、全銘柄が一斉に同方向（下落）へ動き始める。
この「同期」が発生すると、系全体の自由度は実質的に 1（全体がひと塊として動く状態）へと縮退し、そのエネルギーが第1主成分に集中するため、$\lambda_{\max}$ が他の固有値から乖離して劇的に増大する。

\paragraph{診断指標としての有効性}
本研究では、この $\lambda_{\max}$ の値を時系列で追跡することで、前節で述べた「相転移（暴落）の進行度」を定量的に診断する。
複雑なIPR（逆参加率）や固有ベクトルの詳細な解析を行わずとも、$\lambda_{\max}$ という単一の指標を監視するだけで、市場全体を支配する「同期圧力」の総量を把握することが可能である。
すなわち、$\lambda_{\max}$ がノイズ領域 $[\lambda_-, \lambda_+]$ を逸脱して異常な成長を見せた瞬間こそが、市場が臨界状態へ遷移し、
外部ショックに対して脆弱化した「アラート発令」のタイミングと定義できる。

\subsection{市場ポテンシャルと調和振動子モデル}

本節では、本研究が導入する「物理的エネルギー指標」の理論的背景として、古典力学および量子力学における調和振動子モデルと、それを金融市場へ拡張する際のアナロジーについて述べる。

\subsubsection{物理学における調和振動子}
調和振動子（Harmonic Oscillator）は、平衡点からの変位に比例する復元力が働く系であり、物理学において最も基礎的かつ重要なモデルの一つである。
質量 $m$ の粒子が、バネ定数 $k$ のバネに繋がれて一次元上を運動している場合、平衡点からの変位を $x$ とすると、この粒子に働く力 $F$ はフックの法則により $F = -kx$ で表される。
このとき、系に蓄えられるポテンシャルエネルギー（位置エネルギー）$U$ は、力の積分として次式で定義される。
\begin{equation}
U(x) = \frac{1}{2}kx^2
\end{equation}
この式は、**「系が平衡状態から大きく乖離する（$|x|$ が大きくなる）ほど、その二乗に比例して系内部に蓄積されるエネルギーは増大する」**という普遍的な物理法則を示している。

\subsubsection{先行研究における市場モデル}
経済物理学の分野において、この調和振動子の概念を金融市場に適用する試みは既に存在する。
例えば、Ye \& Huang (2008) や Lin (2024) らは、市場価格の変動を量子調和振動子（Quantum Harmonic Oscillator）の波動関数として記述するモデルを提案している。
これらの研究では、市場には価格を長期的均衡点（ファンダメンタルズ）へと引き戻す「市場の力（Market Force）」が存在し、それが調和ポテンシャル $V(x) \sim x^2$ として機能すると仮定している。
この枠組みにおいて、価格 $P(t)$ の均衡点からの乖離 $x(t)$ は物理的な「変位」とみなされ、その二乗項 $x(t)^2$ は市場が抱える「歪み」や「ストレス」の総量を表すエネルギーとして解釈される。

本研究における「エネルギー指標」は、これらの先行研究におけるポテンシャル概念を基礎としつつ、次節で述べる日本市場特有の構造的歪みを反映させるために、変位 $x$ として「対数収益率」ではなく「生株価の絶対水準」を採用する点に独自性がある。

\subsection{金融ネットワークと日本市場の特異性}

前節までの物理モデルに加え、本研究では市場を「相互作用する複雑ネットワーク」として捉える。本節では、一般的な金融ネットワークの構造と、日本市場が持つ世界的に稀な「構造的歪み」について論じる。

\subsubsection{企業間の結合とネットワーク理論}
金融市場において、個別銘柄（企業）は独立して存在しているわけではない。現代の経済活動において、企業はサプライチェーン（供給網）、資本関係、あるいは共通の投資家セクターを通じて密接に結合している。
ネットワーク理論の観点では、各企業をノード（節点）、企業間の相関や取引関係をエッジ（枝）とするグラフ構造として市場を記述できる。Mantegna (1999) らは、株価の相関行列から最小全域木（MST）を作成し、市場には産業セクターごとのクラスタ構造が存在することを示した。
通常、こうしたネットワーク上の「ハブ（重要拠点）」となるのは、時価総額（企業の規模）が大きい巨大企業であると考えるのが経済学的に自然である。S\&P500などの主要な株価指数も、この「規模の論理」に基づき、時価総額加重平均型を採用している。

\subsubsection{日本市場の構造的歪み：値がさ株の影響}
しかし、日本市場（特に日経平均株価を採用する市場環境）においては、この標準的なネットワーク理論が適用できない「異常な構造」が存在する。
それは、**「株価の絶対値（単価）」が高い銘柄が、企業規模に関係なく市場全体を支配してしまう**という歪みである。

\subsubsection{株価加重型指数の特異性}
日本の代表的な株価指数である「日経平均株価（Nikkei 225）」は、世界的にも珍しい「株価単純平均型（Price-weighted）」の指数である。
これは構成銘柄の株価の合計を除数で割って算出されるため、時価総額が小さくとも、単元の株価が高い「値がさ株（High-priced stocks）」の影響力が極端に大きくなるという性質を持つ。
対照的に、米国のS\&P500や英国のFTSE100など、世界の主要指数の殆どは「時価総額加重型（Market-cap weighted）」であり、企業の経済的実態（規模）を正確に反映するように設計されている。

\subsubsection{ファーストリテイリングの事例}
この歪みを象徴する典型的な事例として、ファーストリテイリング（ユニクロ）の存在が挙げられる。
同社は極めて高い株価水準を持つため、一時期は日経平均株価の構成比率の約10\%以上を単独で占めるという異常事態が発生した。これにより、「市場全体（TOPIX）は下落しているのに、ファーストリテイリング1社が上昇しただけで日経平均は上昇する」といった、実体経済と乖離した現象が頻発している。
投資家の多くは日経平均株価をベンチマークとして売買を行うため、結果として**「企業規模（時価総額）よりも、株価の絶対値（生株価）が高い銘柄」**がネットワークのハブとして機能し、市場全体のトレンドを牽引するという、日本特有の力学が形成されている。

したがって、日本市場の暴落を物理モデルで記述するためには、教科書的な「時価総額」や「リターン」だけでなく、この構造的歪みの源泉である**「生株価（Raw Price）」そのものをエネルギーの重みとして組み込むこと**が、工学的に有効であると本研究は考える。

\section{金融市場と機械学習}
本章では、前章で定義した物理的特徴量（RMT指標など）を入力とし、将来の市場変動を予測するための数学的フレームワークとして、機械学習の理論的基礎とその適用について述べる。
\subsection{機械学習の数理的定式化}
機械学習（Machine Learning）とは、工学的にはデータから規則性を抽出するアルゴリズムの総称であるが、物理学的な視点では、未知の確率分布 $P(X,Y)$ から生成された有限の標本集合 
$D=\{(x_i, y_i)\}_{i=1}^N$ に基づき、入力 $x$ から出力 $y$ を写像する関数 $f:X \to Y$ を、汎化誤差（Generalization Error）を最小化するように決定する「変分原理に基づく最適化問題」として定式化される
\subsubsection{経験リスク最小化と正則化}
真の分布 $P(X,Y)$ が未知である以上、期待リスク（真の誤差）を直接計算することは不可能である。そのため、学習は以下の経験リスク $R_{emp}(f)$ を最小化する関数 $f$ を仮説空間 $\mathcal{H}$ から探索する過程に帰着される。

\begin{equation}
R_{emp}(f) = \frac{1}{N} \sum_{i=1}^N L(y_i, f(x_i))
\end{equation}
ここで、$L(y, \hat{y})$ は損失関数（Loss Function）であり、予測値と真値の乖離による「エネルギー」を定義する。
しかし、有限のデータに対して $R_{emp}$ を過度に最小化すると、ノイズまで学習してしまう過学習（Overfitting）が発生する。これを防ぐため、物理学におけるラグランジュの未定乗数法と同様に、
関数の複雑さにペナルティを課す正則化項 $\Omega(f)$ を加えた構造リスク $R_{reg}(f)$ の最小化を行う。

\begin{equation}
\hat{f} = \argmin_{f \in \mathcal{H}} (R_{emp}(f) + \lambda\Omega(f))
\end{equation}
この $\hat{f}$ を求めるプロセスは、統計力学における自由エネルギー最小化や、逆問題解析におけるチコノフ正則化と数理的に等価な構造を持つ。

\subsection{勾配ブースティング決定木とLightGBM}
金融時系列データのような、高次元かつ非線形性が強いテーブルデータに対して、
現在最も高い予測精度を示す手法の一つが勾配ブースティング決定木（Gradient Boosting Decision Tree; GBDT）である。本研究では、その高速かつ高精度な実装である LightGBM を採用する。
\subsubsection{関数空間における勾配降下法}
勾配ブースティングは、単一の予測モデルを作るのではなく、複数の「弱学習器（Weak Learner）」$h_m(x)$ の線形結合によって、最終的な強学習器 $F_M(x)$ を構成するアンサンブル学習手法である。

\begin{equation}
F_M(x) = \sum_{m=1}^M \gamma_m h_m(x)
\end{equation}
このモデル構築過程は、関数空間における勾配降下法として解釈できる。第 $m$ ステップにおいて、現在のモデル $F_{m-1}(x)$ の残差（損失関数の負の勾配）を近似するように新たな学習器 $h_m(x)$ を追加する。

\begin{equation}
h_m(x) \approx - \left[ \frac{\partial L(y,F(x))}{\partial F(x)} \right]_{F(x)=F_{m-1}(x)}
\end{equation}
これは、物理シミュレーションにおける摂動展開や、ポテンシャルの谷底へ向かって徐々に補正項を加えていく反復解法と同様のアルゴリズムである。

\subsubsection{LightGBMの特徴とDeep Learningとの比較}
近年、金融工学の分野においても深層学習（Deep Learning）の応用が劇的に進展している。特に、TransformerやLSTMといったアーキテクチャを用いることで、定量的な価格データだけでなく、
ニュース記事やSNS上のテキスト情報（自然言語）、あるいは企業の財務諸表（ファンダメンタルズ）といった非構造化データを統合的に学習するマルチモーダルなモデルが提案され、高い予測精度を上げている点は無視できない。
しかし、本研究は「ニュースの内容」そのものを解析することではなく、それらが引き起こす「市場内部の構造変化（相転移）」を、数値データ（価格・相関）のみから物理的に抽出することに主眼を置いている。
このようなテーブルデータ（Tabular Data）の解析において、LightGBMは依然として深層学習と比較しても遜色ない、あるいは凌駕する性能を示すことが多くのコンペティション等で実証されており、
以下の物理的・工学的理由から本研究のソルバーとして最適であると判断した。
決定木の非線形分割能力: 決定木ベースの勾配ブースティングは、特徴空間を直交する超平面で分割する。このため、RMT指標（0〜1の範囲とは限らない物理量）や価格変動率といった、
スケールや分布形状が異なる変数が混在していても、正規化の影響を受けずにロバストに非線形境界を学習できる。
低S/N比環境での汎化性能: 第1章で述べた通り、金融市場はシグナルに対してノイズが極めて多い系である。深層学習モデルはパラメータ数が膨大であり、
十分な正則化を行わない限りノイズパターンを過剰に記憶（Overfitting）するリスクが高い。対して、多数の弱学習器（決定木）のアンサンブルであるLightGBMは、統計的に分散を抑制する効果が強く、
限られたデータ量でも安定した汎化性能を発揮する。
GOSSによる計算効率と収束性: LightGBM特有のアルゴリズムである GOSS (Gradient-based One-Side Sampling) は、勾配（学習誤差）が大きい重要なサンプルを優先的に学習に利用する。
これにより、市場の構造変化点のような「学習が難しい局面」に対して効率的に適合することが可能である。
以上の理由から、本研究では「ニュース等の外部テキスト情報」には依存せず、市場の内部状態を示す数値データのみを用いた物理的アプローチの有効性を検証するため、予測器としてLightGBMを採用する。

\section{提案手法}

本章では、市場の「同期現象（タイミング）」と「潜在エネルギー（規模）」の両面から暴落を予知する新たなフレームワークを提案する。


\subsection{解析対象とデータセット}
\subsubsection{解析対象}
本研究では、株式会社日本取引所グループ（JPX）が提供する「J-Quants API」より取得した株式データを使用した。
解析対象としては、東京証券取引所における時価総額および流動性の高い上位100銘柄で構成される「TOPIX100」の採用銘柄を採用した。
\begin{description}
\item[(1) 選定理由] TOPIXを選定した主な理由は二点ある。第一に、市場代表性とシステマティック・リスクの捕捉である。
TOPIX構成銘柄は東証プライム市場の時価総額の大部分を占めており、これらの銘柄群の動向は日本経済全体のマクロな状態を強く反映する。
本研究の目的は、個別企業の事情に依存した特異的な変動（Idiosyncratic Risk）ではなく、市場全体が同期して崩壊する「システマティック・リスク」の検知にあるため、
市場への感応度が高い大型株は最適な対象である。第二に、統計的解析における安定性である。本研究で用いるランダム行列理論（RMT）は、相関行列の固有値解析に基づくため、
データの品質に敏感である。流動性の低い小型株では売買が成立しない日が発生しやすく、これが相関行列に用いる収益差分が0となり、ノイズを生じさせる要因となる。
対して、TOPIX100採用銘柄は極めて高い流動性を持ち、データの欠損や異常値が比較的少ないため、物理モデルの適用に適している。
\item[(2) 本対象の制約] 一方で、TOPIX100を対象とすることには以下の制約も存在する。
まず、生存バイアス（Survivorship Bias）の影響である。本研究では、取得時点におけるTOPIX100構成銘柄の過去データを遡って使用しているため、
過去にTOPIX100に含まれていたが現在は除外されている銘柄（上場廃止や降格など）の影響が考慮されていない。
また、新興市場固有の変動の補足力の限界も挙げられる。
本モデルは大型株の同期現象に特化しているため、グロース市場などで局所的に発生する投機的なバブルや暴落については、検知感度が低下する可能性がある。
\item[(3) データ期間と検証スコープ] データセットの期間は、2016年1月30日から2026年1月15日までの約10年間とした。
本研究では、過去のデータを用いて逐次的に未来を予測する実運用環境を模倣するため、ウォークフォワード分析（Walk-Forward Analysis）を採用している。
これにより、単一の期間だけでなく、以下の異なる市場環境下における複数の主要な暴落イベントに対して検証を行っている。
\begin{itemize}
    \item COVID-19ショック（2020年）： 未知の感染症によるパンデミック性の暴落。
    \item 植田ショック（2024年）： 金融政策の変更（利上げ懸念）に起因する急落。
    \item 関税ショック（2025年）： 地政学的リスクと貿易摩擦によるシステマティックな暴落。   
\end{itemize}
\end{description}
なお、本研究では評価対象（ポートフォリオ）として時価総額加重型であるTOPIX100を採用する一方で、予兆検知モデルの内部パラメータ（相互作用重み）には、
あえて『株価（Price）』に基づく重み付けを採用する。これは、2.4節で述べた日本市場特有の構造的歪みに着目したものである。
日本市場においては、日経平均株価に代表されるように、時価総額の規模にかかわらず単元株価の高い『値がさ株』が相場の雰囲気を主導する傾向が強い。 
したがって、『市場全体の損益（時価総額）を守るためには、
その崩壊のトリガーとなる値がさ株（株価エネルギー）の挙動を監視すべきである』という仮説に基づき、学習と評価で異なる重み付け基準を適用する。

\subsubsection{データ前処理}
取得した生の市場データは、物理モデルへの入力とするには不適切なノイズや不連続性を含んでいる。本研究では、市場の統計的性質を正しく抽出するため、以下の手順で前処理を行った。
\begin{description}
\item[基礎変数の定義と株式分割]
本研究では、市場の状態を記述する最小単位として、時刻 $t$ における銘柄 $i$ の株価（終値）を $P_i(t)$、発行済株式数を $S_i(t)$ と定義する。
企業の時価総額（Market Capitalization） $M_i(t)$ は両者の積で表される。
\begin{equation}
M_i(t) = P_i(t) \times S_i(t)
\end{equation}
株価 $P_i$ は個々の株式の交換レートに過ぎず、企業の資本政策によって恣意的に変更されうる。
典型的な例として株式分割（Stock Split）があり、比率 $k$ で分割されると、株式数は $S \to kS$、株価は $P \to P/k$ となる。このとき時価総額 $M$ は不変である。
\begin{equation}
M' = \frac{P}{k} \times kS = P \times S = M
\end{equation}
しかし、長期の時系列解析では、こうした株式分割などのコーポレートアクションにより価格が非連続的に変化し、解析上の重大なノイズとなる。たとえば、株価が10,000円の銘柄を1$\to$2に分割した場合、
理論上の株価は5,000円となるが、時系列上は「50\%の暴落」と誤認されうる。
このため、本研究では JQuants API で取得可能な「調整係数（比率$k$）」を用いて過去の価格を遡及的に補正し、
資産価値の実質的な連続性を維持した調整後株価時系列を構築した。

\item[欠損値の処理]
RMT（ランダム行列理論）による固有値解析は、行列の次元数（銘柄数 $N$）が全期間を通じて一定であることを前提とする。
そのため、データセット期間中に新規上場（IPO）または上場廃止等の理由でデータが欠損する不完全な銘柄については、統計的な整合性を欠くノイズ源となるため解析対象から除外した。 
具体的には、ソフトバンク(2018年上場)とソニーフィナンシャルグループ(2025年上場のため、同識別コードを使っていた会社のデータを取得する仕様)を削除した結果、解析対象は最終的に N=98 銘柄となった。
また、商船三井および アシックスの2銘柄について、2025年後半の特定期間において「株価$P_i(t)$ は存在するが、時価総額 $M_i(t)$ が欠損している」現象が確認された。 
調査の結果、これは企業の決算発表後に、データプロバイダ側の発行済株式数 $S_i(t) $の更新が遅延したことに起因するシステム的な欠損であることが判明した。
この期間において、当該銘柄に株式分割等の資本異動（$S_i(t)$の不連続な変化）は発生していないことが確認されたため、株式数 $S_i(t)$ は定数とみなすことができる。
$M_i(t) \propto P_i(t) \quad (\text{if } S_i(t)=\text{const.})$
この物理的関係に基づき、本研究では当該期間の時価総額を株価の変動を用いて補完し、解析対象として維持する処置を行った。

\end{description}





\subsubsection{データ抽出と変数の定義}
J-Quants APIからは、企業の財務情報や板情報を含む膨大なデータが取得可能であるが、本研究では物理モデルへの適用に最適化するため、以下の3種類の時系列データを抽出し、解析用データセット（CSV形式）として整備した。

\begin{itemize}
    \item \textbf{生株価（Raw Close Price, $P_{raw}$）}:
    市場で実際に約定した終値。株式分割等のコーポレートアクションによる不連続性を含むが、投資家が実際に目にする価格水準であり、「1万円の大台」といった心理的なポテンシャル障壁（Psychological Barrier）を解析するために保持した。
    
    \item \textbf{調整後株価（Adjusted Close Price, $P_{adj}$）}:
    株式分割や併合の影響を遡及的に補正した理論価格。時系列としての連続性が保たれているため、第2章で定義した「市場ポテンシャルエネルギー（$U \propto P^2$）」の算出や、長期的なトレンド解析における主たる位置変数として使用する。
    
    \item \textbf{時価総額（Market Capitalization, $M$）}:
    発行済株式数と株価の積。不均質イジングモデルにおいて、各銘柄（ノード）が市場全体に及ぼす影響力の重み（相互作用強度 $J_{ij}$）を推定するための質量パラメータとして使用する。
\end{itemize}

これらのデータは、欠損値処理（4.1.2参照）を経た後、銘柄ごとに時系列アラインメントを行い、物理演算用の基礎テーブルとしてデータベース化されている。



\subsection{RMTによる相転移の検知（タイミングの捕捉）}
本研究の第一の柱は、市場の暴落を統計力学的な「相転移」として捉える点にある。
数年に一度発生する中規模以上の暴落（システマティック・リスク）においては、発生直前に全銘柄の価格変動が同期する現象が観測される。
本研究では、ランダム行列理論（RMT）に基づき、相関行列からノイズを除去した「最大固有値」を監視することで、この同期タイミング（いつ相転移が始まるか）を特徴量として抽出する。


\subsubsection{物理モデル適用に向けた前処理}
前節で整備した基礎データに対し、ランダム行列理論（RMT）に基づく相関解析を行うため、以下の統計的変換処理を施した。

\begin{enumerate}
    \item \textbf{対数収益率への変換（運動変数の生成）}:
    RMTによる固有値解析は、データの定常性を前提とする。そのため、調整後株価 $P_{adj}$ の対数差分（Log-return）を計算し、価格のスケールに依存しない「速度」成分 $r_i(t)$ を生成した。
    \begin{equation}
    r_i(t) = \ln P_{adj}(t) - \ln P_{adj}(t-1)
    \end{equation}
    
    \item \textbf{局所的正規化（Local Normalization）}:
    銘柄ごとに異なるボラティリティ（揺らぎの大きさ）を統一し、純粋な相関構造のみを抽出するため、特定の時間窓 $T$（本研究では過去$L$日間のローリングウィンドウ）における平均 $\mu_i$ および標準偏差 $\sigma_i$ を用いて標準化を行った。
    \begin{equation}
    \hat{r}_i(t) = \frac{r_i(t) - \mu_i}{\sigma_i}
    \end{equation}
    これにより、全ての銘柄は平均0、分散1の無次元量に規格化され、ウィシャート行列との比較（マルチェンコ・パスツール則の適用）が可能となる。
    
    \item \textbf{相関行列の構築}:
    正規化された収益率ベクトル $\hat{r}(t)$ を用いて、時刻 $t$ における経験的相関行列 $\mathbf{C}(t)$ を次式で算出した。
    \begin{equation}
    C_{ij}(t) = \frac{1}{T} \sum_{\tau=t-T+1}^{t} \hat{r}_i(\tau) \hat{r}_j(\tau)
    \end{equation}
    この行列 $\mathbf{C}(t)$ の固有値分布を解析することで、次節以降で述べる「市場の同期状態（秩序変数）」を定量化する。
\end{enumerate}


\subsection{第2の柱：生株価エネルギーによる構造的歪みの検知}
第二のアプローチは、日本市場特有の「歪み」を捉えるためのドメイン知識に基づく特徴量エンジニアリングである。
普遍性を重視するRMTとは対照的に、ここでは「価格の絶対水準」を最も重要な変数として扱う。
日本市場においては、時価総額の大小にかかわらず、単元株価（生株価）が高い「値がさ株」が指数のトレンドを主導する傾向がある。この構造的リスクを定量化するため、以下の物理変数を定義する。

\begin{itemize}
    \item \textbf{生株価 ($x$):} ポテンシャル。系におけるエネルギーの高さを決定する。
    \item \textbf{調整株価 ($\tilde{x}$):} 運動。時系列的な変動を記述する。
    \item \textbf{株式数 ($m$):} 質量。
\end{itemize}

これに基づき、本研究独自の\textbf{物理的エネルギー指標 ($I_{phy}$)}を定義する。
\begin{equation}
I_{phy} \propto \sum x \cdot \tilde{x} \cdot m
\end{equation}
この指標は、RMTが見落とす「同期の規模（エネルギー密度）」を独立して評価するものであり、値がさ株に蓄積された歪みを可視化する。

\subsection{独立変数の統合と学習戦略}
本研究の予測モデルは、上記の2つの独立した指標を入力（Input）および学習目標（Target）として統合する。

\subsubsection{特徴量空間の独立性}
入力特徴量として、RMT由来の「固有値スペクトル」と、エネルギー工学由来の「$I_{phy}$ 変動」の双方を使用する。
\begin{itemize}
    \item RMT特徴量は、市場全体が「そろそろ動く」というシグナルを送る。
    \item エネルギー特徴量は、その動きが「致命的な破壊力を持つか」というシグナルを送る。
\end{itemize}
この二つは線形独立な情報であるため、モデルはこれらを組み合わせることで「ノイズ（小規模な同期）」と「暴落（高エネルギーな同期）」を分離可能となる。

\subsubsection{学習ターゲットとしての物理エネルギー}
さらに、学習時の目的変数（正解ラベル）として、経済的な時価総額（$I_{eco}$）ではなく、物理的なエネルギー（$I_{phy}$）を採用する。
これにより、モデルは「金額的な損失」ではなく「物理的なエネルギー崩壊」を最小化するように最適化される。これは、日本市場においてはエネルギーの崩壊こそが、遅れてやってくる経済的損失（$I_{eco}$の下落）の真の原因であるという仮説に基づく。


\subsection{機械学習的観点：信号増幅による学習効率の向上}

本研究が、学習ターゲット（目的変数）として経済指標（$I_{eco}$）ではなく物理指標（$I_{phy}$）を採用する理由は、単なる物理的解釈にとどまらない。
機械学習、特に深層学習における「学習のしやすさ（Learnability）」という工学的観点において、物理指標の導入は以下の明確なメリットをもたらす。

\subsubsection{信号対雑音比（S/N比）の改善}
通常の対数収益率（System 1）に基づく暴落シグナルは、日常的なノイズ（ボラティリティ）との振幅差が小さく、モデルが「真の暴落」と「単なる調整」を区別することが困難である（勾配消失や局所解へのトラップを招きやすい）。
一方、物理エネルギー（System 2）は、株価水準 $x$ を乗じることで変動を非線形に増幅する。
\begin{equation}
\Delta E \approx \Delta P \cdot P \cdot m
\end{equation}
この変換により、株価が高い局面での暴落（致命的なイベント）は、通常の変動に比べて極めて大きな損失値（Loss）として算出される。
結果として、特徴空間における「平時（負例）」と「暴落（正例）」の決定境界（Decision Boundary）が明確化され、モデルの分類精度が向上する。

\subsubsection{不均衡データ問題の緩和}
市場暴落は発生頻度が極めて低い「レアケース」であり、通常の学習ではモデルが多数派である「平時」に過剰適合しやすい（Class Imbalance Problem）。
本手法では、物理指標を用いることで、レアケースである暴落データに対し、物理的な重み（エネルギー量）に基づいた自然なペナルティ強化（Cost-sensitive Learning）を行うことと等価な効果が得られる。
これにより、意図的なデータオーバサンプリング等を行わずとも、モデルは「少数の致命的な暴落」を見逃さないよう重点的に学習することが可能となる。

すなわち、系を変える（物理指標を導入する）という操作は、物理的な意味付けであると同時に、\textbf{「機械学習モデルにとって暴落の特徴を捉えやすくするための、信号増幅フィルタリング」}としての役割を果たしている。

\subsection{学習・評価フレームワークの全体像}


本研究の目的は、物理的な指標導入の有効性を検証することにあるが、単にモデルを一つ作って終わりではなく、入力特徴量の組み合わせ（3通り）と、学習させる目的変数の定義（2通り）を掛け合わせた、計6通りの実験設定（Experimental Design）において比較検証を行う。

特に重要となるのは、**「学習（Training）」と「評価（Evaluation）」の分離**である。
本研究では、モデルがいかなる目的変数（物理エネルギー等）を学習したとしても、最終的な性能評価は一貫して現実の経済的価値（Index 1）に基づいて行う。これは、「物理的な予兆を学習することが、結果として経済的な損失回避に繋がるか」を検証するためである。

\subsubsection{入力モデルの定義（3種類）}
まず、入力特徴量（Feature Set）の構成に基づき、以下の3つのモデルを定義する。

\begin{description}
    \item[Model A: Baseline (Technical Only)] \hfill \\
    従来の金融工学アプローチ。入力変数は、経済空間（価格・出来高）から算出される一般的なテクニカル指標（Return, Volatility, RSI, Momentum等）のみに限定する。これは、物理的アプローチを行わない場合の基準点となる。
    \item[Model B: Hybrid (Baseline + RMT)] \hfill \\
    Model Aに対し、第1の柱である「RMT特徴量（最大固有値 $\lambda_{max}$ 及其の微分項）」を追加したモデル。普遍的な「相転移のタイミング（同期）」情報が加わることで、予測精度がどう変化するかを検証する。RMTは理論的裏付けが強固であるため、この段階で一定の精度向上が見込まれる。
    \item[Model C: Proposed (Full Physical)] \hfill \\
    Model Bに対し、第2の柱である「エネルギー特徴量（生株価 $x$ を含む $I_{phy}$ の速度・加速度）」を追加した完全版モデル。日本市場特有の「構造的歪み」情報を加えることで、更なる精度向上（特に致命的な暴落の検知）が可能かを検証する。これはドメイン適応的なエンジニアリングの側面が強い。
\end{description}

\subsubsection{目的変数の定義（2系統）}
次に、モデルが教師データとして学習する「正解ラベル（Target）」の定義として、以下の2つの系（System）を用意する。

\begin{description}
    \item[Target 1: Economic System ($I_{eco}$)] \hfill \\
    標準的な時価総額加重指数（Index 1）の暴落を正解とする。
    定義：$Target = 1 \iff \Delta I_{eco} \le Threshold$
    これは「お金が減ること」を直接予測させる、一般的なアプローチである。
    \item[Target 2: Physical System ($I_{phy}$)] \hfill \\
    本研究が提案する物理エネルギー指数（Index 2）の崩壊を正解とする。
    定義：$Target = 1 \iff \Delta I_{phy} \le Threshold$
    これは「エネルギーが解放されること」を予測させるアプローチであり、信号増幅効果（4.6節参照）による学習効率の向上が期待される。
\end{description}

\subsection{目的変数の決定と重み付け学習}
\subsubsection{グリッドサーチ}
次に、これら二つのインデックスのどちらを予測ターゲットとすべきか、および判定閾値をどう設定すべきかを決定するため、グリッドサーチによる網羅的な分析を行った。
判定条件は、短期（3日間）と中期（7日間または10日間）の複合条件とし、それぞれのインデックスに対して閾値を変化させた際の「検知件数（Events）」、「平均重み（Avg\_Weight）」、「最大重み（Max\_Weight）」を算出した。

表
%\ref{fig:grid_table}
は、エネルギーインデックスを用いた場合のグリッドサーチ結果の一部である。
（※比較のため、標準インデックスを用いた場合の分析も同様に行ったが、ここでは紙幅の都合上、採用に至ったエネルギーインデックスの結果を中心に議論する。）
ここで、各設定の良し悪しを判断するための指標として、検出された暴落イベントの重みを定量化した。
表\ref{fig:grid_table}における各項目の定義は以下の通りである。
\begin{description}
    \item[Events]: その閾値設定で検知された暴落イベントの総数。
    \item[Avg\_Weight (平均エネルギー強度)]:検知された各イベント期間における「ポテンシャルエネルギー（株価二乗）の解放量」の平均値。具体的には、イベント期間中の各日について
     $P(t)^2 \times |r(t)|$ を算出し、その総和をとったものである。
     \begin{equation}
w(t) = w_{base} \times \underbrace{\exp(-\gamma \cdot \Delta t)}_{\text{時間減衰項}} \times \underbrace{\frac{|R_{long}(t)|}{|\theta_{long}|}}_{\text{強度比例項}}
\end{equation}
ここで、各項の定義と物理的意図は以下の通りである。

\begin{enumerate}
    \item \textbf{時間減衰項 (Time Decay Term):}
    $\Delta t$ は暴落判定（相転移）が開始してからの経過日数、$\gamma$ は減衰率（本研究では0.5）である。
    暴落期間中であっても、実務上最も価値があるのは「発生直後の初動（Nucleation）」である。発生から日が経った後のデータ（余震）の重みを指数関数的に減衰させることで、モデルが「暴落の真っ只中」ではなく「暴落の予兆」に焦点を合わせて学習するよう誘導する。

    \item \textbf{強度比例項 (Severity Term):}
    $R_{long}$ は実際の下落率、$\theta_{long}$ は閾値（-8\%）である。
    ギリギリで判定基準を満たした暴落よりも、基準を大きく下回る壊滅的な暴落（-20\%など）に対して、その倍率に応じたペナルティを与える。これは「エネルギー解放量に比例したコスト関数」を定義することに等しい。
\end{enumerate}
            この値が大きいほど、その定義は「小規模な調整」ではなく「破壊的な大暴落」を選択的に捉えていることを意味する。
\end{description}


\subsubsection{物理的重み付け学習（Sample Weighting）}
不均衡データ問題に対処し、かつ物理的に意味のある「相転移の開始点」をモデルに学習させるため、正例（暴落）データに対して以下の複合的な重み付け関数を導入した。

\begin{equation}
w(t) = w_{base} \times \underbrace{\exp(-\gamma \cdot \Delta t)}_{\text{時間減衰項}} \times \underbrace{\frac{|R_{long}(t)|}{|\theta_{long}|}}_{\text{強度比例項}}
\end{equation}


この重み付けにより、最大重みは約30〜40倍（コード出力値参照）に達し、希少な「大暴落の初動」が学習プロセスにおいて支配的な影響力を持つようになる。

\subsubsection{機械学習モデルへの適合性と最終決定}
二つのインデックスと数多の閾値の組み合わせの中から、本研究では以下の基準に基づきターゲットを選定した。

\begin{enumerate}
    \item \textbf{高エネルギー事象の選別（Avg\_Weightの最大化）}:
    機械学習モデルにおいて、ノイズ（小規模な調整）とシグナル（真正の暴落）を分離するためには、検知されたイベントが物理的に意味のある（重みが大きい）ものである必要がある。
    表\ref{fig:grid_table}の「Avg\_Weight」列に着目すると、閾値を厳しくするほど平均重みは上昇する傾向にあるが、イベント数が極端に減少するトレードオフがある。
    標準インデックスを用いた場合、低価格帯での小規模な下落も多く拾ってしまうため、Avg\_Weightは全体的に低くなる傾向が見られた。対してエネルギーインデックスは、Avg\_Weightが高い水準で維持されており、破壊的な暴落を効率よく捉えられている。
    
    \item \textbf{学習データ数の確保（Eventsの適正化）}:
    不均衡データ学習において、正例（暴落）の数が少なすぎるとモデルは収束しない。表より、イベント数が60〜80件程度確保されている条件が望ましい。
    
    \item \textbf{主要ショックの網羅（Caught列の確認）}:
    2020年のコロナショック、2024年の植田ショック、2025年の関税ショックといった、歴史的に重要な相転移イベントが漏れなく検知されていることが必須条件である。
\end{enumerate}

以上の分析から、本研究では**「エネルギーインデックス」を採用し、かつ閾値として「短期(3d) -2\% かつ 中期(10d) -8\%」の条件（表の下から4行目）**を選定した。
この条件は、イベント数71件（データ全体の約3\%）を確保しつつ、Avg\_Weightが10.43、Max\_Weightが30.64と、バランス良く高エネルギーな暴落を抽出できている。
特に、-2\%という短期閾値は一見緩く見えるが、これを「エネルギーインデックス（生株価乗算）」に適用することで、**「低価格帯のノイズは無視し、高価格帯の-2\%（実額での大きな下落）は逃さず捉える」**という、動的なフィルタリングが機能している点が重要である。

\section{実験結果と考察}

また、特徴量重要度（Feature Importance）の解析を通じ、モデルが物理的な「相転移の予兆」をどのように学習しているか、そのメカニズムを考察する。

\subsection{実験設定と評価指標}

\subsubsection{データセットと期間分割}
実験には、日本市場（TOPIX100構成銘柄）の過去10年分の日次データを用いた。
モデルの汎化性能、および異なる相場環境（レジーム）に対するロバスト性を検証するため、データセットを以下の通り時系列で分割した（表\ref{tab:periods}参照）。



特にテスト期間には、外部要因（地政学リスク）が支配的であった期間と、内部要因（金利・ポジション解消）が支配的であった期間の双方が含まれており、モデルが未知の物理的メカニズムに対して適応できるかを厳格に評価する設定とした。

\subsubsection{比較手法（ベースラインと比較モデル）}
提案手法の構成要素である「RMT特徴量」と「エネルギー特徴量」のそれぞれの寄与を分解して評価するため、以下の3つのモデルを用意した。
すべてのモデルにおいて、学習アルゴリズムには LightGBM を採用し、目的変数の定義（Index 2に基づく暴落判定）およびハイパーパラメータは共通とした。

\begin{enumerate}
    \item \textbf{Baseline (Technical Only):}
    従来の金融工学アプローチ。入力特徴量は、経済空間（Index 1 / $yz$平面）で計算されたテクニカル指標（Return, Volatility, RSI, Momentum）のみを用いる。
    
    \item \textbf{Model A (Technical + RMT):}
    Baselineに加え、市場の「同期（秩序）」を捉えるRMT特徴量（$\lambda_{max}$ およびその微分項）を追加したモデル。相転移の「タイミング」を捉える能力を評価する。
    
    \item \textbf{Proposed (Full Physical Model):}
    Model Aに加え、物理空間（Index 2 / $xyz$空間）で定義されたエネルギー特徴量（$E_{pot}$ Raw/Vel/Accel）を追加した完全版モデル。相転移の「規模（ポテンシャル）」を捉える能力を評価する。
\end{enumerate}

\subsubsection{評価指標}
本研究では、4.4節で定義した「学習系」と「評価系」の分離戦略に基づき、以下の異なる観点から性能評価を行う。

\begin{enumerate}
    \item \textbf{分類性能（Classification Metrics）:}
    不均衡データ（暴落発生率は約3〜5\%）であることを考慮し、正解率（Accuracy）ではなく、適合率（Precision）、再現率（Recall）、およびその調和平均である \textbf{F1-Score} を主要指標とする。
    特に、暴落の見逃し（False Negative）は致命的な損失に直結するため、Recallを維持しつつ、いかに過剰検出（False Positive / オオカミ少年）を抑制できるか（Precisionの向上）を重視する。

    \item \textbf{経済的性能（Economic Metrics / Backtesting）:}
    モデルの信号に従って売買を行った場合の資産推移をシミュレーションする。評価は**経済空間（Index 1 / 調整株価）**で行う。
    \begin{itemize}
        \item \textbf{Cumulative Return:} 最終的な累積リターン。
        \item \textbf{Maximum Drawdown (MDD):} 期間中の最大資産下落率。リスク管理能力を測る最も重要な指標。
        \item \textbf{Calmar Ratio:} 年率リターンをMDDで除した値。リスク対効果の効率性を示す。
    \end{itemize}
\end{enumerate}
