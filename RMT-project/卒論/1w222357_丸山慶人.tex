\section{背景と目的}
近年、金融時系列予測において機械学習が高い精度を示しているが、実用には「説明可能性」と「頑健性」が不可欠である [cite: 4]。従来のブラックボックス的なアプローチは、予測根拠が不明瞭であり、市場のノイズを過剰学習する課題があった [cite: 4]。
本研究の目的は、日本市場の大型株群（TOPIX100）を対象に、ランダム行列理論（RMT）に基づき算出された最大固有値を特徴量としてLightGBMに導入し、説明可能かつ頑健な暴落予測モデルを構築することである [cite: 4]。

\section{研究方法}
\subsection{目的変数の定義と最適化}
暴落を定量的に定義するため、短期（3日後）および中期の累積リターンを用いた以下の複合条件によって正解ラベル $y_t$ を定義した [cite: 7, 10]。
\begin{equation}
    y_t = 1 \text{ if } R_{t+3} \le -0.02 \cap R_{t+10} \le -0.08
\end{equation}
それ以外を0とする [cite: 8, 9]。全期間中、本条件を満たすイベントは97件（約4.4\%）であり、統計的ノイズを除外した「本格的な暴落」を抽出するバランスとしている [cite: 11]。

\subsection{重み付け学習 (Sample Weighting)}
不均衡データ問題を解消するため、学習データに対して重み付けを行う [cite: 13]。$y_t = 1$ に対してその後の最大ドローダウンに比例した重みを付与することで、致命的な暴落の予兆を優先的に学習させる [cite: 13]。

\subsection{入力特徴量の構成}
以下の2種類の特徴量を採用する [cite: 15]。
\begin{itemize}
    \item \textbf{ベースライン特徴量}: Return, Volatility (20d), Momentum (10d), RSI (14d) [cite: 18, 19, 20, 21]。
    \item \textbf{提案特徴量 (RMT指標)}: 相関行列の最大固有値 $\lambda_{\max}$ に着目し、その値（Raw）、1階微分（Vel）、2階微分（Accel）を採用する [cite: 23, 24, 25, 26]。
\end{itemize}

\subsection{予測モデルの構築}
非線形性の考慮、特徴量重要度の算出、不均衡データへの対応が容易なLightGBMを採用した [cite: 28, 30, 31, 32]。

\section{実験結果}
2025年の関税ショックシナリオにおける有効性を検証した [cite: 34]。

\section{結論}
本研究では、RMTに基づく物理指標を機械学習に統合する手法を提案した [cite: 38]。RMT指標の導入により、不均衡データ下での検知能力が有意に改善し、ボラティリティ指標よりも早期のリスク回避が可能となることが明らかとなった [cite: 40, 41]。
